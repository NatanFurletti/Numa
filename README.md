# Numa

Treino de cálculo mental: rodadas curtas de contas com tempo, estrelas e progressão por níveis. Roda na web (PWA) e, depois, em iOS e Android.

## Rodando localmente

Requer Node 22.13 ou mais novo (veja `.nvmrc`).

```bash
npm install
npm run web
```

## Testes e qualidade

```bash
npm test
npm run typecheck
npm run lint
```
